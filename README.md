# Web-Scrapping-Leaning
Learning the Web scrapping Techniques 

Tools: Python (Pandas, NumPy), CoinGecko API

Overview: Created a script to extract and process the top 10 largest global economies by GDP from IMF data. Used web scraping and API requests to gather data, converted JSON to DataFrame, and performed time-based grouping of financial metrics.

Highlights: Data extraction, transformation, and visualization using candlestick charts to analyze daily price movements.
